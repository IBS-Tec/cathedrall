Este documento existe para que **outra pessoa** consiga manter o sistema de pé sem você.
O maior risco deste projeto não é técnico — é que o único mantenedor fique indisponível.
Todo procedimento operacional deve morar aqui, escrito para quem nunca viu o sistema.
